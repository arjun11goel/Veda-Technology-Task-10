# Veda-Technology-Task-10
# AI vs. ML vs. Deep Learning

## Overview
This project provides a clear and concise comparison between Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL). It is designed to help beginners build a foundational understanding of how these three related fields intersect and differ from one another.

## Contents
The repository/notebook includes the following sections:
*   **Definitions & Relationship:** A conceptual breakdown of how ML is a subset of AI, and DL is a subset of ML.
*   **Comparison Table:** A quick-reference table highlighting definitions, key differences, and examples.
*   **Real-World Examples:** Practical applications of each technology to contextualize the concepts.
*   **Python Visualization:** A simple Python script that visually prints the hierarchy of AI, ML, and DL.
*   **Interview Q&A:** Answers to common foundational interview questions regarding AI and ML.

## Technologies Used
*   Markdown
*   Python (for basic text visualization)
*   Jupyter Notebook (recommended environment)

## How to Use
Simply open the provided Jupyter Notebook or Markdown file to review the comparisons. You can execute the Python cell to see the text-based hierarchy visualization.
